1. By using a small time interval $\Delta t$ we can estimate the number of nuclei $\Delta N$ that decay in the time interval $\Delta t$
2. $N$ is the number unstable nuclei at the start of the time interval, we assume that $N$ doesn't change much in $\Delta t$
3. 1st interval $\Delta N = \lambda N_{0} \Delta t$
4. Subtract $\Delta N$ from $N_{0}$ to find $N_{1}$ at the start of the next step $\Delta N = \lambda N_{1}\Delta t$
